## About the files

- Each `<name>.usdz` is named after its device's SVG, so a device's `images` entry in the hardware list maps to its model by swapping the extension.
- Models are real size (meters, Y up) and built from the manufacturer's published dimensions. The shape comes from the front view: outline, face details and thickness are accurate, side and back details are not.
- The copyright notice is also embedded in each file's layer metadata.
- They are generated by `scripts/device-models/`. Change a model's spec there and regenerate rather than editing a model here; `publish-flasher.sh` sends the same files to the web flasher's `public/models/devices/`.
- They ship in the iPhone, iPad, Mac and Vision Pro builds, not Apple TV or Apple Watch. The nightly image sync downloads new and updated models from the flasher and tracks them in `model_manifest.json`; it never removes a file it didn't download.
