# Official asset sources

All artwork in this extension is derived only by resizing official files from
the [`meshtastic/design`](https://github.com/meshtastic/design) repository at
commit `915c3912f70b8bd0522b7253ebb5e6acd52fc342`.

- `Stickers/chirpy.png`: `chirpy/chirpy.png`
- `Stickers/mesh-logo.png`: `logo/png/play_store_icon.png`
- `Stickers/mesh-powered.png`: `Meshtastic Powered Logo/M-POWERED.png`
- `Assets.xcassets/iMessage App Icon.stickersiconset/*`: resized and padded
  variants of `logo/png/play_store_icon.png` required by the Messages icon
  catalog.

No generated, redrawn, or pose-modified mascot artwork is bundled.
