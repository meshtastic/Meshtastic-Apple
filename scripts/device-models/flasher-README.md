## About the files

- Each `<name>.usdz` matches `public/img/devices/<name>.svg`, so a device's `images` entry in the hardware list maps to its model by swapping the extension.
- Each `<name>.glb` is the same model for glTF viewers (Android, desktop, web), converted from the USDZ by `scripts/usdz2glb.py` (`uv run scripts/usdz2glb.py public/models/devices/*.usdz --out public/models/devices`). Regenerate it whenever the USDZ changes.
- Models are real size (meters, Y up) and built from the manufacturer's published dimensions. The shape comes from the front view: outline, face details and thickness are accurate, side and back details are not.
- The copyright notice is also embedded in each file's layer metadata.
- They are generated by `scripts/device-models/` in [Meshtastic-Apple](https://github.com/meshtastic/Meshtastic-Apple). Change the spec there and regenerate rather than editing a model here.
